# 🛡️ ChildMonitor - प्रगत पालक नियंत्रण व बाल सुरक्षा प्रणाली (Parental Control System)

हा एक आधुनिक, सुरक्षित आणि संपूर्ण **Parental Monitoring & Child Safety** प्रकल्प आहे. यात पालकांसाठी एक सुरक्षित **वेब डॅशबोर्ड (Password Protected)**, मुलाच्या फोनसाठी **Android ॲप**, आणि लॅपटॉपवर थेट चाचणी घेण्यासाठी **Mock Client** दिला आहे.

---

## 🔐 सुरक्षितता व पासवर्ड (Security)

पालक डॅशबोर्ड आता पासवर्डने सुरक्षित करण्यात आला आहे.
* **डॅशबोर्ड URL:** `http://127.0.0.1:5000`
* **पालक पासवर्ड (Default Password):** `shreeom`

---

## ✨ नवीन व प्रगत फिचर्स (Key Features)

1. **🔐 पासवर्ड सुरक्षित लॉगिन (Parent Dashboard Authentication):**
   - डॅशबोर्ड अनधिकृत व्यक्तींपासून सुरक्षित आहे. `shreeom` पासवर्ड टाकूनच पालकांना मुलांचा डेटा पाहता येतो.
   - एका क्लिकवर सुरक्षित लॉगआउट (Logout) सुविधा.

2. **⚡ लाईव्ह AJAX रिफ्रेश (No Page Reload!):**
   - डॅशबोर्ड दर काही सेकंदांनी संपूर्ण पेज रीलोड न करता पार्श्वभूमीत (AJAX द्वारे) डेटा अपडेट करतो.
   - पालक ऑडिओ ऐकत असताना किंवा नकाशावर झूम करत असताना पेज अडखळत नाही.

3. **🔔 रिमोट फोन गजर (Remote Alarm / Ring Phone):**
   - मुलगा फोन सायलेंटवर ठेवून विसरला असेल किंवा संकटसमयी पालकांना फोनवर लक्ष वेधायचे असेल, तर डॅशबोर्डवरील **'फोन वाजवा (Alarm)'** बटण दाबून मुलाच्या फोनवर मोठ्या आवाजात गजर वाजवता येतो.

4. **💡 रिमोट टॉर्च नियंत्रण (Remote Flashlight / Torch):**
   - डॅशबोर्डवरून एका क्लिकवर मुलाच्या फोनची फ्लॅशलाईट (टॉर्च) चालू किंवा बंद करता येते.

5. **🗺️ १-क्लिक जिओफेन्स क्रिएटर (Interactive Geofence on Map):**
   - कठीण अक्षांश-रेखांश (Lat, Lon) टाईप करण्याची गरज नाही! नकाशावर कुठेही क्लिक करताच ते स्थान आपोआप सेफ झोन फॉर्ममध्ये भरले जाते.
   - एकापेक्षा जास्त सुरक्षित क्षेत्रे (उदा. घर आणि शाळा) असतील, तर मूल त्यापैकी कोणत्याही एका क्षेत्रात असल्यास खोटा अलार्म (False Alarm) येत नाही.

6. **🗺️ Google Maps थेट नेव्हिगेशन:**
   - डॅशबोर्डवर मुलाच्या लोकेशनजवळ थेट **'Google Maps वर दिशा पहा'** लिंक दिली आहे; त्यावर क्लिक करताच गुगल मॅप्सवर मुलाकडे जाण्याचा थेट रस्ता (Directions) मिळतो.

7. **📊 प्रवास इतिहास (Location History & CSV Export):**
   - मुलाच्या प्रवासाचा संपूर्ण इतिहास तारखेनुसार तक्त्यात पाहता येतो.
   - संपूर्ण ट्रॅकिंग डेटा एक्सेल CSV फाईल स्वरूपात डाउनलोड (Export) करता येतो.

8. **📸 फोटो गॅलरी आणि लाईटबॉक्स (Lightbox Zoom):**
   - फ्रंट आणि बॅक कॅमेऱ्याचे फोटो गॅलरीत दिसतात. फोटोवर क्लिक केल्यास तो मोठ्या आकारात (Full Screen Zoom) पाहता येतो.

9. **🎙️ आधुनिक ऑडिओ प्लेअर (Native Browser Compatibility):**
   - Android वरून थेट AAC / M4A फॉरमॅटमध्ये ऑडिओ रेकॉर्ड होतो, जो सर्व आधुनिक ब्राउझर्समध्ये थेट वाजतो.

10. **🚨 आणीबाणीचे SOS बटण (Emergency SOS):**
    - मुलाने ॲपमधील लाल SOS बटण दाबताच पालकांच्या डॅशबोर्डवर तात्काळ लाल रंगाचा **EMERGENCY SOS ALERT** येतो आणि कॅमेरा/ऑडिओ त्वरित सक्रिय होतात.

11. **🔋 बॅटरी आणि नेटवर्क मॉनिटरिंग:**
    - बॅटरी टक्केवारी, चार्जिंग स्थिती आणि कनेक्टेड वाय-फाय नेटवर्कची माहिती रिअल-टाइम दिसते.

## 🚀 प्रकल्प कसा चालवायचा (How to Run)

### १. सर्व्हर सुरू करणे:
टर्मिनल किंवा पॉवरशेल (PowerShell) उघडून खालील कमांड द्या:
```powershell
cd "D:\Python\PROJECT MANAGMENT SEP26\ChildMonitor"
python server.py
```
सर्व्हर सुरू झाल्यानंतर ब्राऊझरमध्ये हे उघडा:
👉 **http://127.0.0.1:5000**  
(पासवर्ड: `shreeom` टाका)

---

### २. लॅपटॉपवर टेस्ट करण्यासाठी (Mock Client):
दुसरा टर्मिनल उघडून चालवा:
```powershell
cd "D:\Python\PROJECT MANAGMENT SEP26\ChildMonitor"
python mock_main.py
```
- हा क्लायंट दर ५ सेकंदांनी सर्व्हरशी कनेक्ट होईल आणि हालचाल सिम्युलेट करेल.
- डॅशबोर्डवर जाऊन **"Front Cam"**, **"🎙️ आवाज"**, **"🔔 फोन वाजवा"** किंवा **"💡 टॉर्च"** बटणावर क्लिक करून थेट चाचणी घ्या!

---

### ३. मुलाच्या अँड्रॉइड मोबाईलसाठी (`main.py`):
1. `main.py` चालवा किंवा Buildozer द्वारे APK तयार करा:
   ```bash
   buildozer android debug
   ```
2. ॲप मोबाईलमध्ये इन्स्टॉल केल्यानंतर **Settings** मध्ये जाऊन तुमच्या सर्व्हरचा IP पत्ता (उदा. `http://192.168.1.15:5000`) टाका आणि सेव्ह करा.

## 📁 अद्ययावत फाईल रचना (Project Structure)

- `server.py` : पासवर्ड सुरक्षित Flask सर्व्हर, AJAX लाईव्ह API आणि डॅशबोर्ड
- `database.py` : सुधारित SQLite मॉडेल्स, मल्टिपल जिओफेन्स लॉजिक, अलार्म व टॉर्च कंट्रोल्स
- `child_monitor.db` : SQLite डेटाबेस
- `main.py` : Kivy Android ॲप (Background Keep-Alive, Scoped Storage Fix, AAC Audio, SOS, Alarm)
- `mock_main.py` : चाचणीसाठी Windows Mock क्लायंट
- `buildozer.spec` : अनुकूलित APK बिल्ड कॉन्फिगरेशन
- `requirements.txt` : आवश्यक पायथन लायब्ररी
